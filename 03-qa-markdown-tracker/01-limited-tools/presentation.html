Understand the evidence

The supplied file is a call list.

It contains 1,512 selected calls from 42 agents. It does not contain their QA scores, evaluator flags or coaching history. The sampled-call pivot keeps the original names and shows review coverage.

The review uses those agent names on simulated QA rows instead of Demo agent labels. Scores, teams and coaching are examples. Synthetic transaction IDs keep the simulation separate from actual sampled calls, which still await their audit results.

QA averages use underlying scored audits. Unknown markdown results do not count as a pass. Small samples remain labelled.

Run locally

Ready for your review.

  1. Follow portable setup once on Windows, Mac or Linux.
  2. Run python launch.py limited --demo in the QA project folder. Windows also has UPDATE_QA.cmd for a filter form.
  3. Open the generated workbook in Excel desktop. Use Pivot Tables and its yellow filter dropdowns. Double-click a number for source rows.

Use on another device

One project, portable setup.

Standard Python runs the solutions on Windows, Mac and Linux. No user-name paths or Codex installation are required. An optional Docker package provides a repeatable server setup.

The dashboard is the mobile option: phones and tablets use the browser address of an accessible running computer or server. The limited workbook's native PivotTables need compatible desktop Excel.

A fresh checkout creates anonymous example calls if the supplied file is absent. Your configured private input keeps its original names. Company sign-in and shared hosting are still a deployment step; uploading to GitHub alone does not start a shared dashboard.
